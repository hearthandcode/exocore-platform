## Frozen implementation boundary

The implementation may realize only the modules and extension points named by ADR-FOUNDATION-001 and the boundary manifest. A new dependency direction, extension point, native effect, feature, database, provider, or dynamic plug-in is a stop-and-record event rather than an implementation convenience.

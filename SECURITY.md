# Security policy

## Reporting a vulnerability

Please do not open a public issue for a potential security vulnerability or an accidental exposure of private material. Use GitHub's private security-advisory reporting route for this repository instead.

Include the affected version or commit, a minimal reproduction where safe, the impact, and any suggested mitigation. Do not include credentials, tokens, or personal data in the report.

## Scope

The current orientation shell intentionally has no custom native commands, local-file access, data store, provider integration, telemetry, or network service. Future security policy will expand only alongside those capabilities.
